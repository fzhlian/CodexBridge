# 目标

降低模板化、机械化和过度规整的语言特征，使文本更符合真实中文写作的语义推进、句法节奏和作者意图，同时完整保留事实、立场、逻辑和必要专业术语。

执行前优先读取 `references/natural-writing-sources.md`。本技能用于提升写作质量与自然度，不承诺、预测或优化任何“AI 检测器分数”，也不以规避检测为目标。

# 工作流程

1. **确定不可改变项。** 先锁定事实、数字、人名、机构名、引文、法律政策名称、专业术语、作者核心判断和因果关系。除非用户明确要求，否则不得改变这些内容。
2. **识别模板化特征。** 重点检查：
   - 机械使用“首先、其次、再次、最后”“一方面、另一方面、综上所述”；
   - 段落长度和句式过度整齐；
   - 每段都先概括、再解释、再总结，形成重复节奏；
   - 高频使用“值得注意的是”“需要指出的是”“从某种意义上说”等空转连接语；
   - 形容词和抽象名词堆叠，具体动作和主体不足；
   - 无必要的三段式、四点式或对仗排比；
   - 同一个意思换词重复；
   - 结尾无新信息却再次总结全文；
   - 为显得完整而把常识解释得过度充分。
3. **重建语义推进。** 按真实表达逻辑组织句子：重要信息先说，必要背景随后补充；能直接说明因果时不用抽象套话；能用具体动作表达时少用名词化表达。
4. **调整句法节奏。** 长短句自然交替。允许部分段落只承担一个功能，不强求每段结构对称；避免连续多句使用完全相同的句法框架。
5. **提高词汇贴合度。** 优先使用语境中最准确、最常用的词，不为了“高级”而同义替换。专业场景保留行业术语，不把准确术语口语化到失真。
6. **保留作者声音。** 若原文已有明显个人语气、判断力度、行业习惯或叙述节奏，应优先保留，而不是统一改造成“标准答案”式文风。
7. **删除无信息量文字。** 对不增加事实、判断、逻辑或情绪功能的句子直接删减。尤其谨慎处理重复总结、泛化意义、空泛展望和拔高表态。
8. **最终复核。** 确认自然化后没有新增事实、改变立场、削弱专业准确性，也没有通过故意错别字、病句、口语碎片或虚构个人经历来制造所谓“人味”。

# 优先改写策略

- 把“抽象名词 + 进行/实现/形成”改为更明确的动作表达，但仅在含义不变时使用。
- 把可以直接相连的两句话直接相连，不额外插入过渡句。
- 对并列事项数量不作形式化追求；事实只有两点就写两点，不为了“三点式”增加第三点。
- 标题和小标题只在确有信息组织价值时保留，不机械设置“背景—问题—建议—结语”。
- 结尾优先停在真正的结论、行动或判断上，不自动追加“总之”“未来可期”等收束语。

# 不得采用的伪自然化方法

- 不故意加入错别字、标点错误、病句或不必要的网络口语。
- 不虚构第一人称经历、情绪、采访、观察或案例。
- 不随意加入“我觉得”“说实话”“其实”等口头填充词。
- 不通过罕见词、生僻词和无意义句式变化制造随机性。
- 不宣称文本可以“绕过”“骗过”或“保证通过”AI 检测器。

# 与 official-document-writing 技能的关系

若同一任务同时属于党政机关公文写作，先由 `official-document-writing` 确定文种、行文规则、事实边界和规范表达，再由本技能处理不影响规范性的句式、冗余和模板化问题。任何自然化修改都不得改变公文的法定用途、机关关系、政策口径和正式程度。
